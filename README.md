# Promed Hospital — Website

Official website for **Promed Hospital**, a multi-speciality hospital in Banashankari 2nd Stage, Bangalore.

🌐 **Domain:** [promedhospital.co.in](https://promedhospital.co.in)

## About

A single-file, dependency-free website featuring:

- Custom-designed hero with animated stats and floating trust badges
- 8 speciality cards (Orthopaedics, Cardiology, General Surgery, Paediatrics, ENT, Gastroenterology, Physiotherapy, Plastic & Cosmetic Surgery)
- Featured doctor profile — Dr. HP Madhusudan (Joint Replacement & Orthopaedic Surgeon)
- Verified patient testimonials and 4.5★ rating highlight
- Insurance & corporate tie-ups
- Appointment request form with validation
- Embedded Google Map with directions
- Floating call & WhatsApp quick-action buttons
- Fully responsive with reduced-motion support

## Tech

Plain **HTML + CSS + vanilla JavaScript** in a single `index.html`. No build step, no dependencies (fonts loaded from Google Fonts). Just open the file or upload it to any static host.

## Deploy

Upload `index.html` to any web host (or point `promedhospital.co.in` at it). Works on GitHub Pages, Netlify, Vercel, cPanel, or any static server.
